open-rec 推荐效果演示

行为记录 click - expose - buy - collect - stay - 带 的行为会影响下次推荐

猜你喜欢 / 相关推荐 经 rec-client SDK 调用 rec-server 的 /api/recommend； 热门推荐 / 新品推荐 直接读取 Redis 的 hot:{scene} / new:{scene} 召回表。

点击卡片上报 click，卡片进入视口自动上报 expose，离开视口上报 stay（驻留秒数）， 按钮上报 buy / collect。所有上报均通过 SDK 推送到 rec-server。

其中只有 click（成为下次召回的 trigger）和 expose（24 小时内被过滤）会改变推荐结果， buy / collect / stay 会被正确存储但当前没有节点消费。
