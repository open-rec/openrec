The distribution itself is published as [`open-rec/openrec@v0.1.0`](https://github.com/open-rec/openrec/releases/tag/v0.1.0). Every repository has a `release/0.1.0` maintenance branch. The SDK additionally provides `go-client/v0.1.0` for Go module resolution.

Bootstrap artifact contract v15 adds generated `recall/item/item_content_emb.csv`,
`item_title_emb.csv`, and `text_embedding.manifest.json`, replacing the duplicate
hash-based `query_embedding.csv`. This requires the companion rec-algorithm text encoder,
generator and v15 builder/checker, plus the model bundle generated by that version.
Existing rank releases, sequence recall and user ALS vectors are preserved by v14 migration.
The default encoder is configurable by model ID and environment; weights are stored in an
operator-configured cache outside the repositories. These language tables are offline artifacts;
the existing experimental Qwen graph channel uses 8B/4096D vectors and must not consume 0.6B/1024D output.

Bootstrap v16 additionally renames ALS neighbors to `user_als_u2u.csv` and ALS factors to
`user_als_emb.csv`. Companion rec-algorithm jobs, rec-console DAG/index management and
rec-server user graph must use algorithm/channel `user_als_u2u` and serving table
`user-als-u2u`. Existing deployments need a new U2U publication and updated persisted overrides.

Bootstrap v17 renames item/user `sparse.csv` to `text_search.csv`, preserving their
contents. The removed Qwen-only manifest is no longer required or emitted; the bundle
manifest continues to checksum all artifacts. Serving algorithm/channel `sparse` is unchanged.

Bootstrap v18 removes optional `item_content_emb.csv` from the default bundle and retains
`item_title_emb.csv`. The generator supports `--include-content` for explicit offline generation.
The default manifest covers 40 artifacts (27 rank files and 13 recall tables).
